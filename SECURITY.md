# Security policy

## Supported versions

Only the latest release (the newest `v*` tag) gets fixes.

## Reporting a vulnerability

Report it privately through GitHub: **Security** tab → **Report a vulnerability**
(<https://github.com/evocaslab/atlas/security/advisories/new>). Do not open a public issue for it. If you cannot use
GitHub, email **[security@evocaslab.com](mailto:security@evocaslab.com)**.

Include what you found, how to reproduce it and the version. A first answer comes within a week.
